# Official Magic Portfolio adaptation

This application comes from the official [Once UI Magic Portfolio](https://github.com/once-ui-system/magic-portfolio). It retains the official Next.js/Once UI source and component system, customized for Minseok Kim’s academic portfolio.

Run `npm ci`, then `npm run dev`. For GitHub Pages, run `npm run build`; the deployable static files are written to `out/`.

See the [repository README](../README.md) for content locations and deployment, and [TEMPLATE-NOTICE.md](TEMPLATE-NOTICE.md) for provenance and license details.
